# export

Queued exports with media storage and completion notifications.
Read `.api-starter.json` before using this module. Install it with `php artisan api:add export`.
Dependencies: media.
Use Actions, typed DTOs, FormRequests and Resources. Emit Laravel events for optional integrations; never call another module directly.
Never disable security middleware. Add en/fr translations and focused Pest coverage. Run `composer check-all` before concluding.
Use Boost schema and log tools before changing migrations or fixing failures.
