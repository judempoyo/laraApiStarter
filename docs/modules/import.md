# import

Queued CSV/JSON imports with validation and media storage.

Dependencies / Dépendances: media. Composer: none / aucun.

```sh
php artisan api:add import
php artisan migrate
php artisan api:doctor --database
php artisan api:remove import
```

The manifest is the file inventory: `stubs/modules/import/module.json`. Routes, schema, tests, provider, translations and AI resources are copied together. Removal preserves database data and refuses modified files. Remove dependent modules first.
